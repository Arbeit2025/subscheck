# サブスク棚卸しメモ（subscheck）

契約中のサブスクリプションを登録して、「毎月合計いくら払っているか」を一目で確認するための棚卸しメモです。

## 使い方

- **登録**：名前・月額（円）・請求日（毎月1〜31日）を入力します。見直し日とメモは任意です。
- **合計表示**：月額合計と年間換算（月額×12）が自動で計算され、一覧の上に表示されます。
- **削除**：解約したサブスクは「削除」ボタンで消せます（確認ダイアログ付き）。

金額はすべて手入力です。銀行口座やクレジットカードとの連携はしません。

データは SQLite に保存されます。DB のパスは環境変数 `SUBSCHECK_DB` で変更できます。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- 年払いプランは「月額に直した金額」を自分で入力してください（年間換算は月額×12の単純計算です）。
- 見直し日の通知機能はありません。リマインダーが欲しい場合はカレンダー等と併用してください。
- 編集機能はありません（直したい場合は削除して登録し直してください）。
- ログイン機能はありません。Render 無料プランでは SQLite のデータが再デプロイ等で消える場合があります。
